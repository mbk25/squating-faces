# squating-faces

Squating futbol bilgi oyununun oyuncu yüzleri (karikatür). Uygulama görselleri
GitHub Pages üzerinden çeker: `https://mbk25.github.io/squating-faces/f/<id>.webp`

- `index.json` — yayındaki yüzlerin listesi ve sürümleri
- `credits.json` — Wikimedia Commons kaynaklı fotoğrafların yazar ve lisans bilgileri.
  Bu fotoğraflardan türetilen görseller kaynak fotoğrafın lisansıyla (ör. CC BY-SA) paylaşılır.
